Missing results

Pupils with no result yet this year for an assessment their year group has sat. Earlier years aren’t counted.

How "missing" is worked out
  • By default the page looks at the whole current year: a pupil is only missing an assessment if they have no result for it in any data drop so far this year. Pick a single drop at the top to look at just that one.
  • An assessment set to Every data drop (Assessments → Edit → How often it is sat) is checked drop by drop instead.
  • An assessment counts as started once at least one pupil has a result for it.
  • It is then expected from every pupil in the year groups it is set for (Assessments → Edit → Year groups). If no year groups are set, it is expected from the year groups that already have at least one result in that drop.
  • Assessments switched off, and pupils outside those year groups, are never counted as missing. Click a red cell to go straight to entering that result.

This copy runs inside Power Apps and opens the SharePoint lists with your own school sign-in. There is no flow link or passphrase. Who can open it is set by sharing the app in Power Apps; who can change the data is set by the permissions on the SharePoint lists.

With the link built in, nobody has to paste it: save the downloaded file over this one in the SLT folder. Without it, the link is kept in this browser only, never in the file, so a copied file is no use on its own. Each computer pastes it once, and every request also needs the passphrase.

Use it in another school

A blank copy has no pupils, no flow link and its own storage in the browser, so it can sit next to this one without mixing data. The other school builds its own SharePoint lists and flow with the setup guide, then uses Connect to SharePoint in its copy.

Where the data lives

Changes are written to the lists automatically a moment after you stop typing.

How saving works

The header shows Saving… while a change is on its way and Saved, with the time and who, once SharePoint has it. There is nothing to press; Save only skips the short pause.

A copy is also kept in this browser. If the connection drops, the tracker keeps trying, and anything that has not reached SharePoint is offered back to you the next time you open it.

Several people can have the tracker open. It picks up colleagues’ saves by itself every minute while you are not typing. If two people change it at the same moment, the second save is stopped and you choose whose version to keep. Nothing is overwritten without asking.

Only the items you change are sent, so a colleague editing other pupils at the same time is never overwritten. You can also edit the lists directly in SharePoint; the tracker picks that up within a minute. If something goes wrong, each list item's Version history keeps every earlier version.

Curriculum frameworks

Your curriculum as assessable statements. Import the Evidence for Learning text exports (.txt) or the criteria workbook; importing again updates in place and keeps every sign-off. In Edit, tick the 6–10 key statements per level and set half-terms, so staff see a short, current list. Taught in decides which teachers sign it off in staff entry.

The two SharePoint lists for frameworks (Frameworks and StatementMarks) aren’t on the site yet, so frameworks are kept in this browser only. Click Set up the SharePoint lists once to add them.

How the statements suggest a level

At the level a pupil is working in: below Developing% of key statements secure is Emerging, then Developing, and Secure% or more (with none at Not yet) is Secure. No suggestion until Evidence needed% of the key statements have been assessed. A Secure judgement older than Re-check after days is flagged, not discounted. Suggestions never change a level; a level more than one step away asks for a reason.

Curriculum

Levels run 1E to 9S in thirds of a level. These rules decide each pupil’s status. On track = making at least the expected progress a year, measured from the start point you choose.

Projected GCSE grade

Levels are curriculum stages (Level 7 = Year 7 standard), so each pupil is carried on at their own pace to the end of Year 9 and compared with the Year 9 standard (9S). The grade is read from this table: the most a pupil can be behind, in years, and still be likely to get that grade. Defaults follow the national pattern (DfE KS2–GCSE transition matrices: at the expected standard at 11 → median grade 4; about a year behind → 3; two or more years behind → 2). Negative means ahead.

Scales
